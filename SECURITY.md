# Security policy / Política de seguridad

**English.** Orbitae is an educational and scientific tool; the viewer is static, has no third-party JavaScript and
a restrictive Content-Security-Policy. If you find a security problem (for example in the viewer, the build pipeline
or the dependencies), please report it privately through GitHub's "Report a vulnerability" button in the Security tab
of this repository, or by email to amurlaniakea@gmail.com. This is a solo, best-effort project: there is no guaranteed
response time. Only the latest release is supported. Scientific errors (wrong numbers) are not security issues: please
open a normal issue.

**Español.** Orbitae es una herramienta educativa y científica; el visor es estático, no usa JavaScript de terceros y
tiene una política de seguridad de contenido restrictiva. Si encuentras un problema de seguridad (en el visor, en la
cadena de construcción o en las dependencias), avísalo en privado con el botón "Report a vulnerability" de la pestaña
Security de este repositorio, o por correo a amurlaniakea@gmail.com. Es un proyecto personal con el mejor esfuerzo: no
hay un plazo de respuesta garantizado. Solo se da soporte a la última versión. Los errores científicos (cifras
incorrectas) no son problemas de seguridad: abre un issue normal.
